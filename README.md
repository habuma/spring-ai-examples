# Spring AI Examples

This repository is where I'll commit various examples of using Spring AI.

You can clone this project in its entirety and work with it like that. *Or*
better, use the [SpringCLI](https://docs.spring.io/spring-cli/reference/index.html)
to select individual projects and create them locally.

## Project Index

### Core chat and prompting

- [prompts-and-output-parsers](prompts-and-output-parsers) - prompt templates and structured output examples
- [spring-ai-kotlin](spring-ai-kotlin) - basic Spring AI application in Kotlin
- [spring-ai-user-questions](spring-ai-user-questions) - question and answer example with the OpenAI SDK
- [spring-ai-summarizer](spring-ai-summarizer) - document summarization example

### RAG and vector stores

- [spring-ai-rag-example](spring-ai-rag-example) - RAG example with metrics and tracing support
- [spring-ai-rag-chat](spring-ai-rag-chat) - chat-oriented RAG example
- [vector-store-loader](vector-store-loader) - load local files into ChromaDB
- [spring-ai-evaluators](spring-ai-evaluators) - evaluator example with a Qdrant-backed rules corpus
- [spring-ai-kotlin-rag](spring-ai-kotlin-rag) - Kotlin-based RAG example
- [spring-ai-htmx-rag](spring-ai-htmx-rag) - HTMX UI for a RAG assistant

### Tools, skills, and workflows

- [spring-ai-tools](spring-ai-tools) - tool calling basics
- [spring-ai-sql](spring-ai-sql) - natural-language-to-SQL example
- [spring-ai-todo-write-tool](spring-ai-todo-write-tool) - write-tool example for todo updates
- [spring-ai-skills](spring-ai-skills) - Claude-style skills implemented with Spring AI

### Agents and MCP

- [spring-ai-a2a](spring-ai-a2a) - simple A2A agent example
- [spring-ai-mcp-client](spring-ai-mcp-client) - Spring AI MCP client example
- [spring-ai-htmx-mcp](spring-ai-htmx-mcp) - HTMX-based MCP client example
- [jbang-mcp](jbang-mcp) - JBang MCP server and client scripts
- [mcp-apps-server](mcp-apps-server) - MCP Apps metadata example

### Images and multimodal

- [spring-ai-image-gen](spring-ai-image-gen) - image generation example
- [spring-ai-multimodal](spring-ai-multimodal) - multimodal image input example
- [spring-ai-multimodal-audio](spring-ai-multimodal-audio) - multimodal audio example
